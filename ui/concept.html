02 · 闭环故事

工具的第一个用户，就是期末项目自己

01导入

读取 Qoder 真实会话 + 其他 agent 夹具，先看脱敏结果。

02提炼

规则引擎找出重复命令、纠偏语句、依赖偏好，生成带证据的候选惯例。

03审核

逐条接受、改写或忽略；档案由此获得可信度，而不是黑盒结论。

04带走

导出 AGENTS.md / CLAUDE.md / JSON，换一个 agent 直接继承。

04 · 设计立场

三个决定产品性格的选择

01适配器即插件

agent 的日志格式一定会变、一定会多。解析器独立注册，坏一个不影响其他。

02证据优先于结论

不输出「你的品味分」。每条惯例都必须能跳回原文，由人确认后才进入档案。

03档案可移植

不属于任何 agent 生态。今天是 Qoder 的会话，明天可以导出给 Claude Code 用。

不做模型训练 不调用在线模型 不上传会话 不绑定单一 agent 未经确认不改你的配置
